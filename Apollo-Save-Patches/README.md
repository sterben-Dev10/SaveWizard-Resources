# 🎮 Apollo Save Patches

This directory contains backups of Apollo `.savepatch` files and a collection of patches from other repositories.

The official collection is synced from [bucanero/apollo-patches at `99f4e10`](https://github.com/bucanero/apollo-patches/tree/99f4e10e415e1a1590c301b105667530710854fa), including its Python helpers and title-ID catalogues. Upstream files retain their [GNU GPL v3 or later license](LICENSE).

| Platform / collection | Contents |
| --- | --- |
| [PS4](PS4) | Backup of [bucanero's apollo PS4](https://github.com/bucanero/apollo-patches/tree/main/PS4) `.savepatch` files. |
| [PS3](PS3) | Backup of [bucanero's apollo PS3](https://github.com/bucanero/apollo-patches/tree/main/PS3) `.savepatch` files. |
| [PS2](PS2) | Backup of [bucanero's Apollo PS2](https://github.com/bucanero/apollo-patches/tree/main/PS2) `.savepatch` files. |
| [PSP](PSP) | Backup of [bucanero's apollo PSP](https://github.com/bucanero/apollo-patches/tree/main/PSP) `.savepatch` files. |
| [PSV](PSV) | Backup of [bucanero's apollo PSV](https://github.com/bucanero/apollo-patches/tree/main/PSV) `.savepatch` files. |
| [Python helpers](python) | Upstream helper scripts distributed with the patch database. |
| [Other](Other-PS4) | Backup collection of PS4 `.savepatch` files from other repositories. |

`Other-PS4` contains the custom collection and is excluded from upstream syncs. This README is maintained locally.
